# VibeCoding 0.4.0

Released 03.11.2026

## What's new

- The page «Правила»: write a rule by sender address, domain (subdomains included) or subject words,
  with a target project and a thread name, or none for «Неразобранное». Edit or delete it in place.
- A new chain matching a rule goes into the rule's project and thread before the engine, even into a
  project you have not filled yet; the thread is created when the project has none of that name.
- «Заполнить» places the project's chains by its rules first and gives the rest to the engine; a chain
  whose rule points to another project stays out.
- When several rules match, an address wins over a domain, a domain over subject words, then the
  earlier rule.
- A chain placed by a rule shows «Правило» and the rule, for example «Правило · домен
  techsnab.example», and keeps showing it after you change or delete the rule.
- A rule never moves a chain placed by hand or taken out of projects, and a new rule never moves a
  chain already placed.

## Under the hood

- Database migration 0007 adds the rules table and lets a placement be made by a rule; it runs when
  the backend starts.
- When two chains join, a placement by hand wins over a rule's and a rule's over the engine's.
