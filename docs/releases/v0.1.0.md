# VibeCoding 0.1.0

Released 29.10.2026 · the first release

## What's new

- The app runs locally with one command: the backend, the web app in Russian and the database.
- Anyone registers on their own with a name, an email and a password and confirms the email by the
  link in the letter; until then sign-in is refused.
- Sign-in with email and password; the email is matched without regard to case and surrounding spaces.
  After 5 wrong passwords in 15 minutes sign-in for that email is locked for 15 minutes.
- A sign-in lasts 14 days; «Выйти» ends it at once and leaves other devices signed in.
- A forgotten password is reset by an emailed link valid for 1 hour; setting a new password ends every
  session.
- Every user sees only their own data; requests from other sites are refused.
- The service page shows whether the server and the database answer.

## Fixes

None: this is the first release.

## Breaking changes

None for users of a release: there was none before. Development databases of earlier builds with
organizations are converted when the backend starts: every user stays a separate account with the same
email and password, and organizations, roles, invitations and deactivation go away.

## Under the hood

- FastAPI backend, React SPA and PostgreSQL in Docker; the web app talks to the backend only through a
  client generated from the API schema.
- In development every service email is caught by Mailpit at http://localhost:8025; a real SMTP server
  is set in `.env`.
