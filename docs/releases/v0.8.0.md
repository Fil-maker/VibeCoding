# VibeCoding 0.8.0

Released 05.11.2026

## What's new

- On the page of a reply chain every attachment of an email shows its name, its type and its size,
  for example «договор.pdf · PDF · 1,2 МБ». Emails read before this version show their attachments
  without a size.
- A click on an attachment downloads the file under its own name, byte for byte as in the mailbox.
  The app fetches it from a connected mailbox that holds the email, only reads it, and keeps no copy
  of the content. The email stays unread and unchanged in the mailbox.
- When a file cannot be fetched, the reason shows under that attachment: «Файл недоступен: ящик
  отключён», «Письмо больше не найдено в ящике», «Не удалось получить файл: не удалось войти в ящик»
  or «Не удалось получить файл: сервер не отвечает». The status of the mailbox does not change.

## Under the hood

- Database migration 0009 keeps the size of each attachment next to its name; it runs when the
  backend starts.
- The API gains `GET /api/v1/emails/{email_id}/attachments/{index}`; an attachment of another
  user's email answers «not found». The reply chain answer lists `attachments` with an index, a name
  and a size instead of `attachment_names`.
