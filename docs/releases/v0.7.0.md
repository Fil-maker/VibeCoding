# VibeCoding 0.7.0

Released 05.11.2026

## What's new

- On the page of a project «Изменить» changes its name and description, by the same checks as when
  the project is created. «Проекты», «Правила» and the chain pages show the new name.
- Changing the description moves no chain. A filled project then shows «Описание изменено после
  заполнения: нажмите «Заполнить», чтобы пересобрать проект» until you fill it again.
- «Удалить проект» asks first, naming how many chains leave the project and how many rules are
  deleted. After «Удалить» you land on «Проекты»; «Отмена» changes nothing.
- The chains of a deleted project stay in «Переписка» with all their emails and show «Вне проектов ·
  убрана вручную». Neither filling another project, a rule nor new mail places them again; only you
  do, by hand. The rules leading into the project are deleted with it. No email is deleted.

## Under the hood

- Database migration 0008 adds the time a project's description last changed; it runs when the
  backend starts.
- The API gains `PATCH /api/v1/projects/{project_id}`, `GET /api/v1/projects/{project_id}/deletion`
  and `DELETE /api/v1/projects/{project_id}`; a project of another user answers «not found».
