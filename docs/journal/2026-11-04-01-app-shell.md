# App shell and user path

Date: 04.11.2026 · Task: 1.7 · Change: 1-7-app-shell

## Goal

The user asked: «добавим полноценный фронтенд с учетом UI и UX потенциальных пользователей. Готовимся к релизу».
The SPA still looked like a skeleton: a guest did not see what the app does, a new user was not told what to
do first, and sections could be reached only through the start page. Task 1.7 gives every signed-in page
one frame (header with sections and the user's menu), a landing page for guests, first steps on the start
page, and one look for loading, empty and error states. SPA only: no API, backend or migration changes.
The visual system (themes, buttons, badges, phone layout of page content) was split off as task 1.8.

## Mistakes and lessons

- Sign-out landed on «Вход» instead of the landing page. react-router 7 wraps navigation in
  `startTransition`, so the cleared session reached `RequireUser` before the move to `/`. `flushSync` alone
  failed because the router update stayed a transition; clearing the session in an effect was rejected as
  setState in an effect. A scenario test of «Выйти» ending on the landing (FR-49) and the manual flow caught
  it; the lesson is to test the end state of navigation flows, not only the click.
- The tab title bugs: `Waiting` produced «VibeCoding — VibeCoding» while the session loaded, and the start
  page's title depended on effect order (working and tested, but fragile, as the code step itself noted).
  The invariant review in `/finish` caught both; a test of the title during loading would have caught the
  first earlier.
- The `app-shell` line of the requirements map and «Last FR number: FR-52» could not be added during the code
  step: before archiving, the link to the spec is broken and `just check` fails. This is done only at
  archive time, so the order of the steps matters.
- The `auto` test mode picked only unit suites, while «Done when» requires `just test-all`; the AI noticed
  and ran everything with the database.
- The database suite (311) ran before the last frontend-only fix and was not rerun.
