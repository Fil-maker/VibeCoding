# VibeCoding

An app that analyses the sentiment of emails, so nobody has to form an opinion of a counterparty by hand.
Every assessment shows the emails and phrases it rests on. Stage: idea, no code yet.

## Start

Requires git, Docker, [uv](https://docs.astral.sh/uv/), [just](https://just.systems/),
[prek](https://github.com/j178/prek), node with pnpm, and OpenSpec
(`npm install -g @fission-ai/openspec`).

```bash
just setup
just check
```

`just dev` is planned (task 0.1 «Application skeleton»).
